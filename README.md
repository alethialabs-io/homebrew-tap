# Alethia Homebrew Tap

Homebrew formulae for [Alethia](https://alethialabs.io) — the multi-cloud Kubernetes control plane and its `alethia` CLI.

## Install

```sh
brew install alethialabs-io/tap/alethia
```

Or tap once, then install by the short name:

```sh
brew tap alethialabs-io/tap
brew install alethia
```

Upgrade with `brew upgrade alethia`.

> Formulae here are published automatically by [GoReleaser](https://goreleaser.com) on each `cli-v*` release. Do not edit them by hand.
